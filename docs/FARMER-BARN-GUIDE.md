# Farmer Barn Design Guide

Optional worksite for `Farmer`s. Not a farmhouse.

Farmers sleep in ordinary village housing. The barn is for the composter, seed, hay, tools, and wet-weather work. An unattended village should be able to add one after it already has a starter farm.

Use [STRUCTURE-BLUEPRINT-GUIDE.md](STRUCTURE-BLUEPRINT-GUIDE.md) for layers and symbols.

## Design Goals

- Read as a barn, not a house: wide door, loft, hay, no parlor.
- Shelter the `Composter` so farm work has a dry corner.
- Hold seed, bone meal, and hay without becoming a second warehouse.
- Do not add Farmer beds. If a bed sneaks in, the design has drifted into a farmhouse.

## Suggested First Pass (Tier 1)

| | |
| --- | --- |
| Footprint | About 7×9 including walls, or 9×11 if a small animal lean-to is included |
| Height | 5–6 layers: ground, loft, simple gable |
| Interior | Open ground floor, loft over half the plan, wide front opening |
| Workstation | `W` / `Composter` under the loft or just inside the wide door |
| Storage | 1–2 chests or hay-bale cells; hay can be `K`-adjacent only if we need a smoke hole, otherwise use note-tagged hay |

**Rooms:** one room plus loft. A fenced side yard is optional and should not compete with the Butcher's cattle pens.

**Materials:**

- `L` / `P` local wood walls and roof
- `M` low stone foundation
- Wide `D` or gated `G` opening, two blocks, so a villager and a player fit
- `U` interior light, `T` outside the door
- No stained glass, no steeple

**Look:** founding workwear of buildings. Patched boards are fine.

## Later Tiers

Not required for the first barn. If the same site upgrades later:

- Tier 2: cleaner wood, cobble plinth, a second loft chest.
- Tier 3: stone-and-wood, copper lanterns, maybe a small grain bin.
- Tier 4: prestige trim only. Still a barn.

Do not grow this into a cathedral of agriculture.

## Construction Rules

- A village with a working farm and spare wood/stone may start a barn on its own.
- Prefer to wrap or sit beside the existing composter rather than invent a second farm.
- Farmers keep using the whole farm territory; the barn is the indoor end of that loop.
- Butcher pens and Shepherd sheep pens stay outside this building.

## What To Hand Over

One clear Tier 1 barn: front, layers or a `P`-key snapshot, composter cell, loft, and a note that there are no beds. Tier 2–4 sketches can wait.
